PRAVEEN S PORTFOLIO — SIMPLE HTML VERSION

Everything that used to be generated by JavaScript is now written directly in HTML.

FILES:
- index.html          Home
- about.html          About
- skills.html         Skills
- projects.html       Project list
- project-*.html      Individual project case studies
- experience.html     Experience
- achievements.html   Achievements
- certifications.html Certifications
- resume.html         Resume
- contact.html        Contact
- css/style.css       Design and responsive styling
- js/main.js          ONLY interactive behavior (menu, filters, photo, 3D hero, form, tilt)

EDITING:
1. Open the HTML page you want.
2. Change the visible text directly.
3. Do not edit JavaScript to change project/skill content.
4. Replace "your-email@example.com" with your email in index.html, contact.html and js/main.js.
5. Replace LinkedIn/Instagram links with your real profiles.

RUN:
Open public/index.html in a browser. For the 3D hero, an internet connection is used for the Three.js CDN.
