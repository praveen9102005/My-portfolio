PRAVEEN S PORTFOLIO — SIMPLE HTML VERSION

Everything that used to be generated by JavaScript is now written directly in HTML.

FILES:
- public/index.html   Home
- public/about.html   About
- public/skills.html  Skills
- public/projects.html Project list
- public/project/     Individual project case studies
- public/Intern_experience.html Internship experience
- public/certifications.html Certifications
- public/resume.html Resume
- public/contact.html Contact
- public/css/style.css Design and responsive styling
- public/js/main.js    ONLY interactive behavior (menu, filters, photo, 3D hero, form, tilt)
- public/photo/        Profile and site images
- public/project_photo/ Project screenshots

EDITING:
1. Open the HTML page you want.
2. Change the visible text directly.
3. Do not edit JavaScript to change project/skill content.
4. Replace "your-email@example.com" with your email in public/index.html, public/contact.html and public/js/main.js.
5. Replace LinkedIn/Instagram links with your real profiles.

RUN:
Open public/index.html in a browser. For the 3D hero, an internet connection is used for the Three.js CDN.
