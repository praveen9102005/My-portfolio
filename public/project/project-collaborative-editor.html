Overview

Multi-user editor where changes appear on every screen as they are typed.

Problem

Sharing files back and forth causes version conflicts.

Solution

A shared document with live sync between connected users.

Key features

  • Live multi-user editing
  • Instant sync over WebSockets
  • Presence indicators
  • Autosave

System architecture

React client→WebSocket→Node.js server→Document store

Challenges

Merging simultaneous edits without losing text.

Future improvements

CRDT-based conflict handling and comments.
